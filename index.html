Protein Pantry

A Website for Healthy Culinary Ideas

Protein Pantry is a student-made website created over the course of the JMU Fall 2025 semester. We encapsulate API datasets as well as responsive design mechanics in order to display dynamic data on our webpage. We use both the Spoonacular API as well as the Giphy API which are both open source and easy to access. Spoonacular helps to retrieve recipe data pertaining to user-searched terms while Giphy uses the recipe information provided to search for the most relevant GIF for a given recipe.
